| [repo-review](.claude/skills/repo-review/SKILL.md) | Survey the WHOLE build, drive the running app, verify swarm claims | Yes, small fixes only | 165 |

**How they route:**
- *"do D4"* / *"pick up the next issue"* → `resolve-issue`
- *"review workstream D"* / *"is this PR solid?"* → `critical-review` (a scope is named)
- *"how is it going"* / *"is this demoable"* → `repo-review` (no scope named, subject is the project)

Each one's description explicitly points at the other two, so the disambiguation is built into the frontmatter rather than left to guesswork.

Beyond these three, `.claude/` also carries non-skill agent tooling: `launch.json` (browser preview targets, including the `dev-localhost` variant that works around the in-app browser blocking `*.lvh.me` subresources) and `settings.json` (denies `npm`/`yarn` and force-pushes, plus a `PreToolUse` hook blocking commits on `main`).

They landed late in the build — PRs [#67](https://github.com/pauljurgens11/shopify/pull/67), [#68](https://github.com/pauljurgens11/shopify/pull/68), [#69](https://github.com/pauljurgens11/shopify/pull/69), [#71](https://github.com/pauljurgens11/shopify/pull/71) — after most of the 30 completed issues were already merged, so the bulk of the swarm never actually ran under them.
